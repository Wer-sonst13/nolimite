# NoLimite Mod (Fabric 1.21.4)
- Taste Rechts-Shift öffnet das NoLimite-Menü (änderbar unter Steuerung -> NoLimite)
- Elemente ziehen = verschieben, Mausrad = Größe, Buttons = an/aus
- Einstellungen: config/nolimite.json

Bauen: Repo bei GitHub hochladen -> Actions -> Artifact "NoLimite-Mod" -> .jar in den mods-Ordner des Profils.
